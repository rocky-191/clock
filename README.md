# ⏰ 模拟时钟

一个简洁优雅的模拟时钟单页应用，实时显示当前时间。

## 功能

- 🔴 圆盘时钟，指针平滑走动
- ⏱️ 数字时间同步显示
- 📅 显示日期和星期
- 📱 响应式设计，支持移动端
- 🌙 深色渐变背景

## 预览

在线访问：https://clock-csl.pages.dev

## 技术栈

- 纯 HTML/CSS/JavaScript
- Canvas 绘制时钟
- requestAnimationFrame 流畅动画

## 本地运行

```bash
python3 -m http.server 3000
```

访问 http://localhost:3000
